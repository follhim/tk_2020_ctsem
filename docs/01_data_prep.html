bar_pct <- function(data, var) {
  ggplot(data, aes({{ var }})) +
    geom_bar(aes(y = after_stat(count / sum(count) * 100))) +
    geom_text(aes(y = after_stat(count / sum(count) * 100),
                  label = after_stat(paste0(round(count / sum(count) * 100, 1), "%"))),
              stat = "count", vjust = -0.3) +
    labs(y = "Percent") +
    scale_y_continuous(expand = expansion(mult = c(0, 0.15)))
}

1.5 Separating Floor Effect

Important

Luckily, Muthen et al. actually came out with a pretty clever and theoretically meaningful way to address floor effects: a hurdle modeling approach.

Instead of dropping the floor effect (the lowest value possible), Muthen et al. recommends creating two variables from the original variable.

Step 1: Create a binary variable.
Create a binary variable that collapses all non-floor scores as 1. Thus, conceptually this variable represents whether a construct is meaingfully occuring or not.

BIN = 0, the construct is not meaningfully occuring. BIN = 1, the construct is meaningfully occuring.

We do loose information about the magnitude of how this construct is taking place, but that’s where part 2 comes in.

Step 2: Create a continuous variable.
In the second step, we code all floor effects as NA (i.e., missing) and retain non-floor effects as original.

Thus, the continous variable is represents what is taking place AFTER removed floor effects which drowned out the variance.

Thus, in analytical models we should include both variables (only possible in SEMs) and allowed to correlate with one another. In doing so, we can understand if a distal variable is related to the occurrence of a construct AND also when it is occurring, the magnitude of that relationship.

For the truncated variable, we will use a tobit/censored specification.
