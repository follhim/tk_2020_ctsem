3.2 PSX Index (Censored)

3.2.1 Model Specification

psx_sum_ctsem <- "
# Measurement Model
psx_B =~ esm_psx_sum
psx_W =~ esm_psx_sum

# Between/Trend
psx_B  ~  psx_B
psx_B ~~  0*psx_B
psx_B %~% psx_B

# Within (dynamic) factor
psx_W  ~  psx_W
psx_W ~~  psx_W
psx_W %~% psx_W

## T0MEAN
psx_B ~t0~ 1

CENSOR: esm_psx_sum
"

psx_censored_syn <- ct_lavaan(psx_sum_ctsem, data = p3_data)

psx_censored_mod <- ctModel(
  type          = "ct",
  id            = "id",
  time          = "time_day",
  latentNames   = psx_censored_syn$latentNames,
  manifestNames = psx_censored_syn$manifestNames,
  LAMBDA        = psx_censored_syn$LAMBDA,
  DRIFT         = psx_censored_syn$DRIFT,
  DIFFUSION     = psx_censored_syn$DIFFUSION,
  T0VAR         = psx_censored_syn$T0VAR,
  CINT          = psx_censored_syn$CINT,
  T0MEANS       = psx_censored_syn$T0MEANS,
  MANIFESTMEANS = psx_censored_syn$MANIFESTMEANS,
  manifesttype  = psx_censored_syn$manifesttype,
  censormin     = psx_censored_syn$censormin,
  censormax     = psx_censored_syn$censormax,
  n.TIpred      = 3,
  TIpredNames   = c("zpos", "zneg", "zdis")
)

effect_cols <- c("zpos_effect", "zneg_effect", "zdis_effect")

# Reverted per request: apply TIpred moderation to every parameter (both
# the between/trait psx_B and within/dynamic psx_W processes), matching
# ctModel()'s own default (tipredDefault = TRUE leaves every cell's effect
# columns TRUE already) rather than restricting to psx_W only. No blanket
# off/selective re-enable here anymore -- this block just confirms/leaves
# the default in place and prints it for visibility.
psx_w_idx <- match("psx_W", psx_censored_syn$latentNames)
target_psx_w <- psx_censored_mod$pars$matrix == "DRIFT" &
  as.character(psx_censored_mod$pars$row) == as.character(psx_w_idx) &
  as.character(psx_censored_mod$pars$col) == as.character(psx_w_idx)

# Safety check: ctModel() has been observed to silently default
# indvarying = FALSE on a free DRIFT diagonal parameter even when nothing
# in this script asked for that. Confirm psx_W's autoregression is still
# individually varying, and force it back on if ctModel() defaulted it off.
stopifnot("indvarying" %in% names(psx_censored_mod$pars))
psx_censored_mod$pars[target_psx_w, "indvarying"] <- TRUE

print(psx_censored_mod$pars[psx_censored_mod$pars$matrix == "DRIFT",
                             c("matrix", "row", "col", "indvarying", effect_cols)])

Important

Although model fit is acceptable, conceptually, a censored/tobit model doesn’t make sense when we know the floor effect, truly reflects the floor.

It’s why we will perform a hurdle/two-part approach below. In this approach, we apply the censored model for the truncated variable, which implies there is indeed values below the new floor that has been artificially induced, and thus continuous.

3.3 Two-Part Approach (Censored Magnitude)

3.3.1 Model Specification

psx_twopart_ctsem <- "

TIPRED: zpos, zneg, zdis
# Measurement Model
## BINARY
bin_psx_B =~ esm_psx_bin
bin_psx_W =~ esm_psx_bin

## CONT.
con_psx_B =~ esm_psx_con
con_psx_W =~ esm_psx_con

# Between/Trend
bin_psx_B  ~  0*bin_psx_B
bin_psx_B ~~  0*bin_psx_B
bin_psx_B %~% bin_psx_B

con_psx_B  ~  0*con_psx_B
con_psx_B ~~  0*con_psx_B
con_psx_B %~% con_psx_B

bin_psx_B %~% con_psx_B

# Within (dynamic) factor
## BINARY
bin_psx_W  ~  bin_psx_W + bin_psx_W:zpos + bin_psx_W:zneg + bin_psx_W:zdis
bin_psx_W ~~  bin_psx_W
bin_psx_W %~% bin_psx_W

## CONT.
con_psx_W  ~  con_psx_W + con_psx_W:zpos + con_psx_W:zneg + con_psx_W:zdis
con_psx_W ~~  con_psx_W
con_psx_W %~% con_psx_W

## T0MEAN
bin_psx_B ~t0~ 1
con_psx_B ~t0~ 1

# esm_psx_con ~ 1

BINARY: esm_psx_bin
CENSOR: esm_psx_con
"

Important

Since this indicator only reflects whether PSX was endorsed or not, it carries no information about how severe the experience was. The drift here captures the rate at which the “just endorsed PSX” state fades back to baseline likelihood.

Technical interpretation: when an individual reports PSX, the elevated likelihood of reporting PSX again decays at a specific rate (−3.482) — i.e., endorsing PSX at one moment tells you little about whether they’ll endorse it again shortly after; occurrence is not “sticky.”

Important

Since this indicator captures how intense/severe PSX is (not just present/absent), the drift here captures the rate at which elevated severity returns to baseline. A slow return to equilibrium indicates high inertia.

Technical interpretation: when someone reports greater PSX, that elevated severity tends to persist — it takes longer to decay back down to their typical (floor) level, rather than resolving quickly.

Putting them together: occurrence is volatile (endorsing PSX at any moment doesn’t predict endorsing it again soon), while magnitude is inertial (once severity rises, it stays elevated for a while before subsiding) — i.e., whether someone reports PSX fluctuates quickly, but how bad it is when they do tends to linger.
